# 보고서뚝딱

유튜브 영상이나 내 영상·음성 파일을 **자막 + 요약 보고서(HTML·PDF)** 로 만들어 주는 Windows 앱이에요.
내 Claude 또는 ChatGPT **구독 로그인**으로 요약해요(API 키·추가 결제 없음).

## 내려받기

👉 **[최신 버전 내려받기](https://github.com/morabitandro-dotcom/report-ttukttak/releases/latest)** → `ReportTtukttak_Setup_<버전>.exe`

1. 설치 파일을 실행해요. "Windows의 PC 보호" 창이 뜨면 **[추가 정보] → [실행]** (코드 서명이 없어서 처음에만 떠요).
2. 관리자 권한 없이 내 계정에만 설치돼요: `%LOCALAPPDATA%\Programs\보고서뚝딱`
3. 처음 켜면 안내(약관 → AI → 저장 폴더 → 형식 → 받아쓰기 → 텔레그램 → 편하게 쓰기)를 따라가면 돼요.

> **0.1.3 이하를 쓰고 있다면:** 앱 안 업데이트가 끝까지 안 될 수 있어요. 위 링크에서 최신 설치 파일을 받아 그대로 실행하세요(덮어 설치, 설정·보고서·기록은 그대로). 0.1.4부터는 앱 안에서 업데이트돼요.

## 필요한 것
- Windows 10/11 64비트, Microsoft Edge(PDF 만들 때 씀, 기본 설치돼 있음)
- AI 하나 이상
  - Claude Pro/Max + Claude Code: 명령 창에서 `claude` 실행 후 `/login`
  - ChatGPT Plus/Pro + Codex: 명령 창에서 `codex login`

## 기능

### 기본
- 유튜브 주소를 붙여 넣거나 내 파일을 끌어다 놓고 **[요약 시작]**
- 보고서: 표지·목차(쪽번호), 개요·**핵심 세 줄**, 장별 요약, **발언자 주장과 AI 시사점 구분**
- 근거마다 영상 **시각 링크**, 자막에서 확인 안 된 숫자는 따로 표시
- PDF 크기: **A4 · 태블릿 · 스마트폰**

### 보고서 정리 그림 (내용에 맞을 때만 자동으로)
흐름도 · 비교표 · 타임라인 · 핵심 숫자 카드 · 장단점·찬반 · 원인과 결과 나무 · 실행 단계 · 막대·선 차트

### 편한 기능
- **주소 여러 개**를 한 번에 붙여 넣으면 차례로 요약(동시에 1~3개)
- **요약할 구간**만 고르기(예: `12:30~28:00`)
- **예약**, AI 사용 **한도에 걸리면 풀릴 때 자동으로 이어서**
- **채널 자동 요약**: 정해 둔 유튜브 채널에 새 영상이 올라오면 자동으로 요약
- **텔레그램**으로 보고서 받기(자동 전송, 다시 보내기)
- **내 보고서 스타일**: 자주 쓰는 요청을 이름 붙여 저장
- **받아쓰기(Whisper)**: 자막 없는 영상·내 파일도, 자동 자막의 빈 곳 채우기(선택)
- **장면 캡쳐**(표·슬라이드를 보고서 그림으로)와 **영상 저장**(약관 동의 후)
- **브라우저 버튼**(즐겨찾기 막대)으로 보던 영상을 바로 넣기, 복사한 주소 알림

### 결과 관리
- 같은 영상은 **버전으로 묶어** 보기, **본문까지 검색**
- 제목 바꾸기 · 저장 폴더 열기 · **삭제(휴지통)** · 여러 개 골라 지우기
- **새 버전 만들기**(요청만 바꿔 다시), **자막 고치고 다시 만들기**(잘못 들은 말 바로잡기)
- **백업·복원**: 보고서·설정·기록을 파일 하나로 새 PC에 옮기기
- **기본 폴더** 하나만 고르면 자막·보고서·영상 폴더가 그 아래로

## 업데이트
앱의 **설정 → 정보 · 업데이트 → [새 버전 확인] → [설치]** 한 번이면 돼요. 켤 때 하루 한 번 새 버전을 확인하고, 확인 값(`SHA256SUMS.txt`)이 맞을 때만, 진행 중인 작업이 끝난 뒤 설치하고 다시 켜져요. 설정과 보고서는 그대로 남아요. 유튜브 받기 부품(yt-dlp)은 따로 자동 업데이트돼요.

## 지우기
Windows 설정 → 앱 → 보고서뚝딱 → 제거. 만든 보고서(`문서\보고서뚝딱`)와 설정(`%LOCALAPPDATA%\보고서뚝딱`)은 남아요.

## 문제가 생기면
앱이 갑자기 꺼지거나 멈추면 `%LOCALAPPDATA%\보고서뚝딱\crash.log` 파일을 보내 주세요. 원인을 바로 찾을 수 있어요.
